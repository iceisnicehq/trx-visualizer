A MAP, NOT ANOTHER MIXER

Your 1 TRX, made visible.

Choose Everyone together for the combined flow. Choose an owner on the left to follow that person's original stake, including transfers between other wallets.

  1. Network: circles are wallets, ring colours are ownership shares. Arrows show transfers in the selected frame. Click a wallet or arrow for exact Sun amounts. Click any wallet on any day to see its full address history.
  2. Journey timeline: wallets stay in fixed columns, repeated on each day. Time runs downward. Each node shows its number, last three address characters, tracked balance and ownership shares. Scroll through days; Ctrl/⌘+scroll zooms. Click a node for its complete transaction history.
  3. Play: each day or transaction lights up for the selected duration. Pause, scrub or step back at any time. Forecasts use dashed lines.
  4. Your data: the public page reads one shared saved snapshot. Only the administrator can publish a replacement JSON using Admin upload and the server-validated publishing password. Visitors can download My 1 TRX CSV or Everyone CSV without a password.

“Before the plans” is enabled by default and includes legacy RANDOM/LIST/REBALANCE history using the existing FIFO convention. Every plan starts a new accounting period; its boundary is not a real transfer. Incomplete data stops balance reconstruction rather than inventing funds.

Sharing: a successful admin upload is stored on the server and becomes visible to everyone on refresh. The previous saved snapshot is retained if validation or upload fails. The publishing password is never included in the public page, CSV or JSON.
